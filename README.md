# Responsive Landing Page

## About the Project

This project is a responsive landing page developed as part of my Web Development Internship at Prodigy InfoTech.

The main purpose of this project is to create a clean, attractive, and user-friendly webpage that works properly on different screen sizes such as desktops, laptops, tablets, and mobile devices.

## Purpose

The purpose of this project is to demonstrate basic web development skills, including:

- Creating a structured webpage using HTML
- Designing the webpage using CSS
- Adding interactive features using JavaScript
- Creating a responsive layout for different screen sizes
- Implementing an interactive navigation menu

## How It Works

The webpage contains a navigation menu that remains accessible while scrolling through the page.

The navigation menu changes its appearance when the user:

- Hovers over a menu item
- Scrolls down the webpage

JavaScript is used to detect user interactions and scrolling, while CSS is used to control the appearance and responsive design.

The page contains different sections such as:

- Home
- About
- Services
- Contact

Users can click the navigation links to move to the corresponding sections of the webpage.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Key Features

- Responsive design
- Fixed navigation menu
- Hover effects
- Scroll-based navigation styling
- Smooth navigation between sections
- Mobile-friendly layout
- Interactive user interface
